# 🛒 Modern MERN E-Commerce Platform

A fully functional, production-ready e-commerce ecosystem featuring a slick customer **Frontend**, a powerful **Admin Dashboard**, and a robust **REST API**.

---

## 🔗 Live Demo
* **Customer Store:** [https://mern-ecommerce-frontend-nu-three.vercel.app/]

---

## ✨ Features

### 🛍️ Customer Frontend
- **Responsive UI:** Crafted with Tailwind CSS for a seamless experience on mobile, tablet, and desktop.
- **Dynamic Search & Filters:** Quickly find products by category, price, or name.
- **Shopping Cart:** Persistent cart state using local storage.
- **Secure Checkout:** Integrated with **Stripe** and **Razorpay** for global payments.
- **Order Tracking:** Real-time status updates for user purchases.

### 🛠️ Admin Dashboard
- **Inventory Management:** Full CRUD (Create, Read, Update, Delete) for products.
- **Image Uploads:** Powered by **Cloudinary** for high-performance image hosting.
- **Order Fulfillment:** Manage customer orders and update shipping statuses.

### 🔐 Security & Backend
- **JWT Authentication:** Secure login for users and restricted access for admins.
- **Environment Safety:** Secure handling of API keys using `.env`.
- **Database:** Optimized NoSQL schemas with **MongoDB Atlas**.

## 🚀 Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js, Vite, Tailwind CSS, React Router |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB Atlas |
| **Auth** | JSON Web Tokens (JWT), Bcrypt.js |
| **Payment** | Stripe, Razorpay |
| **Hosting** | Vercel (Frontend/Admin), Render (Backend) |
